Coffee Shop Sales Dashboard – Excel Project

This project showcases my ability to analyze and automate business data using Microsoft Excel. I worked with a dataset of over 5,000 coffee shop sales transactions to uncover product trends, customer behavior patterns, and key performance insights.

Tools and Techniques Used:

- Pivot Tables for dynamic summarization
- VBA for automation (e.g., auto-refresh, button-driven filters)
- Data cleaning and transformation (handling blanks, errors, data types)
- Conditional formatting and slicers for interactivity
- Charts and visual KPIs to enhance reporting

Key Features:

- Interactive dashboard with filters for product, category, and date range
- Automated refresh and navigation using VBA
- Visual insights into top-selling items, sales by category, and customer trends
- Clean layout for easy understanding by non-technical users

Why this matters:

The dashboard improves reporting efficiency and provides decision-makers with fast, visual access to critical sales metrics. It’s ideal for small businesses looking to make sense of their daily operations without advanced tools.
